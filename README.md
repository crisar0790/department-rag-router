# Department RAG Router

A Python application that classifies support questions and routes them to specialized RAG agents for HR, Technology, and Finance.

The project will use LangChain for orchestration and Langfuse for workflow tracing and automated response evaluation.

## Planned features

- Intent classification and conditional routing.
- Three specialized RAG agents with separate knowledge collections.
- Complete workflow tracing with Langfuse.
- Automated response evaluation with scores from 1 to 10.
- A command-line interface and a demonstration notebook.

## Current status

Initial repository setup. Implementation has not started yet.
